Versión adaptada a HTML5 + CSS3 + Tailwind CSS (CDN)

Archivos principales:
- index.html
- productos.html
- nosotros.html
- contacto.html
- carrito.html
- checkout.html

Cómo usar:
1. Abra index.html en su navegador.
2. Para una mejor experiencia, use Visual Studio Code con Live Server.
3. No necesita npm ni React.

Notas:
- El carrito usa localStorage del navegador.
- El formulario de contacto y checkout son demostrativos.
- El buscador redirige a productos.html con la búsqueda aplicada.
