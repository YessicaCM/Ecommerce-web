Objetivo del proyecto
 Desarrollar una plataforma de comercio electrónico para la venta de videojuegos, permitiendo a los usuarios registrarse, autenticarse, explorar productos, gestionar un carrito de compras y realizar pedidos de manera segura y eficiente.

Tecnologías utilizadas

PHP
MySQL
HTML5
CSS3
JavaScript
Bootstrap
Git y GitHub 

Responsabilidades

Participación en el diseño y desarrollo de la plataforma web.
Implementación de funcionalidades de autenticación y gestión de usuarios.
Desarrollo del módulo de carrito de compras y proceso de checkout.
Creación y gestión de la base de datos en MySQL.
Colaboración en la administración de productos y pedidos.
Trabajo coordinado con el equipo para la integración y prueba de las distintas funcionalidades.

Logros obtenidos

Desarrollo exitoso de una aplicación web funcional para la gestión de ventas de videojuegos.
Fortalecimiento de conocimientos en desarrollo web con PHP y bases de datos MySQL.
Aplicación de conceptos de autenticación, gestión de sesiones y operaciones CRUD.
Adquisición de experiencia en trabajo colaborativo y coordinación de tareas en equipo.
Mejora de habilidades para la resolución de problemas y el desarrollo de proyectos de software en entornos académicos.

Archivos principales:
- index.html
- productos.html
- nosotros.html
- contacto.html
- carrito.html
- checkout.html

Cómo usar:
1. Abra index.html en su navegador.
2. Para una mejor experiencia, use Visual Studio Code con Live Server.
3. No necesita npm ni React.

Notas:
- El carrito usa localStorage del navegador.
- El formulario de contacto y checkout son demostrativos.
- El buscador redirige a productos.html con la búsqueda aplicada.
